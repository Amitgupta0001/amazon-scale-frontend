## 📌 Overview

AmazonScale Frontend is the client application for the AmazonScale e-commerce platform.

The project is designed to demonstrate production-grade frontend engineering practices while integrating seamlessly with the AmazonScale Spring Boot backend.

The focus is on:

- Scalable architecture
- Clean code principles
- Modern React ecosystem
- Performance optimization
- Type-safe development
- Responsive user experience
- Maintainability
- Production readiness

---

# 🎯 Project Goals

- Build a scalable React application
- Consume REST APIs exposed by the Spring Boot backend
- Implement secure JWT authentication
- Learn modern frontend engineering practices
- Follow enterprise project architecture
- Maintain high code quality
- Build a production-ready user interface
